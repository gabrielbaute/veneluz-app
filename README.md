# VeneLuz (Android Client)

En este repositorio estamos desarrollando, paso a paso, el cliente en android para la aplicación de VeneLuz. El objetivo es tener un cliente simple y ligero que permita reportes rápidos con el minimo esfuerzo por parte del usuario.

## Completados
- [x] Modelos de datos y enums para la API
- [x] ApiClient y rutas de conexión
- [x] Errores personalizados
- [x] Servicio de reporte de eventos eléctricos
- [x] Provider el servicio de eventos eléctricos
- [x] Módulo de Themes y visual
- [x] Piovider de la gestión de themes
- [x] Componentes básicos: AppBar, BottomBar, RefreshButton, ReportButton
